# Windows Process Investigation

## 1. Objective
To inspect running processes on a Windows system, understand their resource usage, and learn how to identify unfamiliar processes.

## 2. Tools Used
- Windows 11
- Task Manager

## 3. Procedure
1. Opened Task Manager using Ctrl + Shift + Esc.
2. Navigated to the Processes tab.
3. Observed running applications and background processes.
4. Examined CPU, memory, disk, and network resource usage.
5. Learned how to investigate unfamiliar processes by checking their names and properties.

## 4. Observations
- Windows runs multiple processes simultaneously to support applications and operating system functionality.
- Processes consume different amounts of CPU and memory depending on their activities.
- Background processes may run even when their associated applications are not actively being used.
- Identifying a process by name alone may not be sufficient to determine whether it is legitimate or suspicious.

## 5. Security Relevance
Process monitoring is an important activity in security investigations. Unexpected processes, unusual resource consumption, or suspicious process behaviour may require further investigation.

However, high CPU or memory usage alone does not indicate malicious activity.

## 6. Conclusion
This exercise provided introductory experience with Windows process monitoring and resource usage analysis. It helped develop awareness of running processes and the importance of investigating unfamiliar process behaviour before drawing conclusions.
