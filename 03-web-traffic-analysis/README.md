# Web Traffic Analysis Using Chrome Developer Tools

## 1. Objective
To observe network requests generated when accessing a website and understand how browser resources are loaded.

## 2. Tools Used
- Google Chrome
- Chrome Developer Tools
- Network Tab

## 3. Procedure
1. Opened Google Chrome.
2. Accessed the CNN website.
3. Opened Chrome Developer Tools.
4. Navigated to the Network tab.
5. Observed the network requests generated by the webpage.
6. Examined request names and resource information.

## 4. Observations
During the exercise, the following information was observed:

- Total requests: 91
- Transferred data: 1.8 MB
- Total resources: 9.4 MB
- Different webpage resources, including JavaScript files, fonts and images, were visible.

## 5. Analysis
The Network tab helps developers and security learners understand how a webpage communicates with servers and loads resources.

It can also help identify unusual requests, unexpected external connections and potentially suspicious resource loading behaviour.

The total number of requests does not necessarily represent the number of unique domains.

## 6. Security Relevance
Network traffic analysis is useful for understanding website communication and identifying potentially suspicious network activity.

## 7. Conclusion
This exercise provided introductory hands-on experience with Chrome Developer Tools and webpage network request monitoring.

## 8. Learning Outcome
- Learned to access the Network tab.
- Observed webpage network requests.
- Understood transferred data and resource sizes.
- Learned how browser developer tools can support basic network investigations.
